# 题型指南（L2）

本目录存放按题型聚合出的表达风格指南（`*.json`），由
`scripts/ingest_exemplars.py` 在摄入多篇同题型卡片后自动生成，也可以手工编写。

## 题型分类体系（v1）

| 标签 | 含义 | 典型关键词 |
|---|---|---|
| `optimization` | 优化/调度/规划/决策类 | 优化、调度、规划、配送、路径、排班、选址、分配 |
| `physics` | 物理机理/运动/材料类 | 物理、运动、轨迹、速度、加速度、材料、干涉、弹道 |
| `forecasting` | 预测/时序类 | 预测、时序、时间序列、趋势、预报、客流 |
| `evaluation` | 评价/比较/决策分析类 | 评价、评估、评分、综合、比较、层次分析 |
| `data_mining` | 数据挖掘/分类/识别类 | 分类、聚类、挖掘、识别、检测、特征、异常 |

## 聚合规则

- 同一 `(problem_type, contest)` 分组的卡片才会被聚合到同一份指南。
- 至少 3 篇卡片共有的章节/图表/文风才进入 `common_*` 字段；
  不足 3 篇的特征只保留在单篇卡片的 `highlights` 中，作为弱信号。
- 聚合结果可手工修改，重新运行摄入脚本会覆盖同名文件。
